# Fileport 005 — pocket wallet

Install on Android Chrome: visit https://fileport.abundent.org/, use Install Link Wallet when available or Chrome menu > Install app / Add to Home screen. Launch the installed app. Android's Share menu should offer Link Wallet after installation and share-target registration. Share one HTTPS URL (or text containing exactly one HTTPS URL). The worker accepts only same-origin POST navigation to /api/wallet-capture, parses bounded form data, redirects to a local fragment draft, and does not forward the POST to the server. Without active worker control, server refuses the route; copy/paste fallback. No service worker caching of any content or API, no automatic offline save or background sync.

The fragment is cleared immediately by app initialization; a pending draft uses tab sessionStorage for up to 15 minutes across StaticID login (browser storage is plaintext, not a vault; may survive reload or tab restoration; expiry is enforced on access, not a guaranteed physical deletion timer). No link contents in server query string, no server preview/fetch, no auto-save. Shared title/URL are untrusted; owner reviews them, adds collection/note and presses Save link after authenticated wallet retrieval. Draft is discarded on cancel, sign-out or successful save. Do not share passwords/API keys. Share tokens are sensitive. Review actual URL rather than trusting title. If a browser loses session storage during OAuth, re-share after login. Existing #share invitation receiver is distinct and unchanged. Android Chrome is the target; share-sheet registration and login roundtrip require actual device testing. Desktop install supported when browser offers it; iOS Add to Home Screen may work but native share-target support not promised.

Tests: manifest, icon dimensions, URL parsing, ambiguity, expiry, POST conversion, scope and no-cache source checks. Test installed Android share from browser/music app, signed in and logged out, cancellation, exact URL fragment, PC refresh, expired draft, and recipient invitation playback. No new service or database, no link inventory copied.
